========================================================================================
CONTEXT-FLIP EXPERIMENT (natural multi-context promoters)  --  seed 42
========================================================================================
Primary model: HybridGatedFusion   |   Test samples: 4451

Setup: some promoters appear in the test set under >= 2 different biological
contexts (variety / tissue / stage). The promoter sequence is identical across
those rows; only the context differs. We check whether the model predicts a
different regulation direction (up vs. down) for the same promoter across its
real contexts.

----------------------------------------------------------------------------------------
KEY RESULTS
----------------------------------------------------------------------------------------
  Unique promoter sequences in test set:              3792
  Promoters appearing under >= 2 real contexts:       551
  ... with a change in ACTUAL (ground-truth) label:   232 (42.1%)
  ... with a change in HybridGatedFusion PREDICTED direction: 209 (37.9%)

----------------------------------------------------------------------------------------
PER-MODEL PREDICTED DIRECTION-CHANGE RATE (same natural setup)
----------------------------------------------------------------------------------------
  Model                      # changed   % changed
  HybridGatedFusion                209       37.9%
  HybridLSTM                       210       38.1%
  HybridCNNAttention               226       41.0%
  HybridMultiScaleCNN              232       42.1%
  HybridMLP                        221       40.1%
  HybridTransformer                263       47.7%
  CrossAttentionFusion             286       51.9%

Interpretation: for the same promoter sequence, changing only the biological
context changes the predicted regulation direction for a substantial fraction of
multi-context promoters. This shows the model's prediction depends on biological
context, not the promoter sequence alone -- validating the context-conditional
design. The actual-label change rate is the real-data reference.
